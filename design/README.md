# Designreferens

Bilderna här är underlaget som sidans utseende är byggt och mätt mot. De ligger utanför `docs/`, så de publiceras inte på GitHub Pages.

| Fil | Innehåll |
| --- | --- |
| `referens-design.png` | Originaldesignen (4912 × 2702 px) med alla fyra vyer. Från Mikael, 2026-11-24. |
| `desktop-start.png` | Skrivbord, före lottning/namnfältet (1440 × 1000 px). Utklipp ur originalet. |
| `desktop-resultat.png` | Skrivbord, resultatet med personens namn (1440 × 1000 px). |
| `mobil-start.png` | Mobil, namnfältet (390 × 1060 px). |
| `mobil-resultat.png` | Mobil, resultatet (390 × 1259 px). |

De fyra utklippen är i den storlek sidan visas i, så de går att lägga bredvid en skärmbild av sidan. Kuvertet, tomten och loggan på sidan (`docs/img/`) är utklippta ur de här bilderna.

Texten i designen var delvis på engelska och har översatts till svenska på sidan. Platshållaren `<namnet på personen>` ersätts av personens förnamn.

Efter designen har två saker lagts till som inte finns i bilderna: tomten som vandrar in och drar fram namnet på datorvy, och att kuvertet och tomten ligger under textrutan på mobil.
